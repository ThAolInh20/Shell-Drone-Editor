# 3D花火＆ドローンショーシミュレーション - Shell Drone Animation

[English](README.md) | [Tiếng Việt](README-vn.md) | [日本語](README-ja.md) | [简体中文](README-zh.md)

**Drone Shell Editor**は、花火とドローンのための3Dシミュレーションソフトウェアです。花火の演出脚本の作成、ドローン編隊の設計、花火とドローンを融合させたショー全体の総合的な演出・振付をサポートします。

---

<video src="public/preview/preview-ds.mp4" controls width="100%"></video>

## 本ソリューションの強みと特徴

- **リアルな3D空間環境:** 99%のリアルなシミュレーション体験を提供。
- **多彩な花火ライブラリ:** 100種以上の花火テンプレートとエフェクトを標準搭載し、組み合わせにより最大500種類の花火バリエーションを作成可能。
- **JSON形式によるデータ統一管理:** 同期が容易で、スムーズな共有と連携を実現。
- **高い実行安定性:** 100〜200個の花火の同時打ち上げでも安定動作を保証。
- **プロ仕様の洗練されたUI:** エディター向けに最適化・標準化されたワークフロー。

- **イベント主催者およびショー制作会社:** 「花火」および「ドローン」演出の直感的な3Dシミュレーションとリアルな事前プレビューを作成。

## 主要機能モジュール

### 1. インタラクティブ3Dシミュレーション空間
- 観客席視点、俯瞰視点、技術視点などを自由に切り替え可能なオービタルカメラシステムを備えた3Dステージ環境。
- リアルな星空、ダイナミックライティング、地面反射を再現する夜間環境シミュレーション。

![show-preview](/public/preview/show-preview.png)

### 2. タイムライン演出エディター
- 花火の打ち上げイベントとドローンの状態遷移タイミングを楽曲オーディオトラックと精密に同期。
- ドラッグ＆ドロップ操作により、炸裂時刻、打ち上げ高度、方向、展開角度をミリ秒単位で微調整可能。

![Timeline](/public/preview/timeline.png)

### 3. 3D静的ドローンフォーメーションスタジオ
- 3次元空間内で静止ドローンフォーメーションをモデリング・配置する設計ツール。
- 2D画像からのベクトル抽出、3Dメッシュモデルのインポート、自動ポイント配置アルゴリズムをサポート。

![drone-formation](/public/preview/drone-formation.png)
### 4. ドローンステップ＆アニメーションエディター
- サブグループごと、タイムステップごとにドローン群の連続的な移動アニメーションを制御。
- 滑らかな軌道補間、飛行速度制御、衝突防止経路の自動計算。

![drone-animation](/public/preview/drone-animation.png)

## ダウンロードとインストール

### 一般ユーザー向け

1. プロジェクトの**[GitHub Releases](https://github.com/ThAolInh20/Shell-Drone_3d/releases)**ページにアクセスします。
2. Windows用の最新インストーラー（`.exe`または`.zip`形式）をダウンロードします。
3. 解凍またはインストーラーを実行してソフトウェアを起動します。

*注意: インストール時にWindows SmartScreenの警告が表示された場合は、「詳細情報 (More Info)」をクリックし、「実行 (Run anyway)」を選択してください。*

---

## 開発者向けガイド

本プロジェクトの実行には **[Node.js](https://nodejs.org/)** バージョン 18 以上が必要です。

### ステップ 1: リポジトリのクローンと依存関係のインストール
```bash
git clone https://github.com/ThAolInh20/Shell-Drone-Editor.git
cd shell-drone-animation
npm install
```

### ステップ 2: アプリケーションの起動

#### Electronデスクトップアプリモード (推奨)
直接保存機能や高速ナビゲーションを備えたスタンドアロンアプリを起動します:
```bash
npm run electron:dev
```

#### Webブラウザモード
Vite開発サーバーを起動します:
```bash
npm run dev
```
ターミナルに表示されたローカルアドレス（デフォルト: `http://localhost:5173/`）にアクセスします。

### ステップ 3: パッケージング (ビルド)
Windows用インストーラーとしてコンパイルおよびパッケージ化する場合:
```bash
npm run electron:build
```
パッケージ化されたファイルは `dist-electron` ディレクトリに出力されます。

## クイックショートカットキー

- **Space:** シミュレーション再生 / 一時停止。
- **Ctrl + S:** デスクトップモードで変更内容をソースファイルに直接保存。
- **Ctrl + 1:** メインタイムライン演出エディターへ切り替え。
- **Ctrl + 2:** 3D静的ドローンフォーメーションスタジオへ切り替え。
- **Ctrl + 3:** ドローンステップ＆アニメーションエディターへ切り替え。
