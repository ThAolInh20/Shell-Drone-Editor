# Release Notes - v2.2.4

## Features
- Added drag-to-resize sidebars in the Drone Editor and Formation Designer to customize workspace views.
- Added volume settings config to centralize controls for main volume and sound effects.
- Added drone color preset config to easily customize and centralize color options.
- Added automatic height-based firework sound triggers using two new sound effects.

## Bug Fixes
- Fixed sound files failing to play by migrating from remote AWS S3 URLs to locally hosted assets.

## Updates
- Synchronized translation files for all languages (English, Vietnamese, Chinese, Japanese) with shortened buttons.
- Re-arranged Export and Import buttons side-by-side in the File panel for cleaner space usage.
- Re-arranged visual option checkboxes side-by-side in the Selection panel to save screen space.
- Simplified audio loading code logic and centralized height constants.

## Chores
- Created development automation skills for documentation and translation synchronizations.
- Updated project documentation files.
